# math-journey

数学视野拓展 × Lean 形式化的学习产出仓库

## 坐标系方法

每个新概念都要在四条主线上定位，回答"它在这张图的哪里"：

1. **公理化**：欧几里得 → 非欧几何 → 希尔伯特 → ZFC
2. **分析**：微积分 → 严格化 → 勒贝格 → 泛函
3. **代数**：方程 → 伽罗瓦 → 抽象代数 → 范畴论
4. **逻辑**：康托尔 → 罗素悖论 → 哥德尔 → 图灵 → Curry–Howard → 证明助手

## 目录

- `reading/` — 读书笔记，按四条主线组织；每个新概念标注坐标系位置 + Lean 化尝试。
- `formal/` — Lean 4 定理与陈述；遵循内核最终裁判、禁 sorry-laundering、语义逐行自查。
- `notes/` — 工程日志（AI 在哪里帮了 / 踩了什么坑）、Zulip 问答存档、Anki 词汇表。

## 工具栈

Lean 4 + Lake + Mathlib，配合 VS Code 的 Lean 4 扩展。本仓库的 Lean 文件以仓库根目录的 `lean-toolchain` 所指定的版本为准（如果将来引入）。
